# Security policy

## Scope

This repository is the public source for Appearance Studio Core and links to separate platform previews. Report the affected platform, exact release or commit, and whether the issue concerns Core or a linked preview. Public release candidates and unsigned previews do not imply a stable, signed or fully validated product. No support or patch SLA is promised.

## Confidential reporting

Use the [private vulnerability reporting form](https://github.com/GOD13emad/AppearanceStudio-Core/security/advisories/new) (Security → Report a vulnerability). Include impact, prerequisites and a minimized reproduction with redacted diagnostics. Do not disclose exploit details, credentials, private configuration, personal files or unredacted logs in public issues. If the form is unavailable, request a confidential maintainer contact without sharing vulnerability details publicly.

## Release integrity

Verify downloads against their published checksums; a checksum is not a publisher signature. Preserve existing release-specific acceptance and signing limitations. This repository-level reporting policy does not modify historical release archives or their manifests.
